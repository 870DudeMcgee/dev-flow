# Legacy Dev-Flow Software Factory Archive

Date archived: 2026-05-27

This directory preserves documentation from the previous Dev-Flow direction so it does not remain in active agent context.

The archived material describes the old software-factory workflow: task packets, peer orchestrator lanes, PLAN/CONTEXT/TEST/IMPLEMENT/VERIFY/REVIEW/REPORT rituals, local worker routing, artifact-only model workers, unified-diff patch gates, memory, traces, evals, DAGs, and related runbooks.

It also includes old `.devflow` task packets, reports, generated context maps, orchestrator notes, and the previous advisory constitution. Those files are preserved for historical reference only.

That material is no longer the process authority for rebuilding Dev-Flow.

Active source of truth:

- `docs/control-room-mvp.md`
- `docs/roadmap.md`
- `docs/agent-handoff.md`
- `README.md`

Legacy docs may still contain implementation ideas worth salvaging, especially worktree isolation and verification helpers, but they must be read as historical notes only.
