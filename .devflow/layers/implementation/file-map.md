# File Map

- `.devflow/project/`: project-wide orientation and machine-readable project state.
- `.devflow/goals/bootstrap-devflow-filesystem/`: active bootstrap goal.
- `.devflow/context/`: classified reusable context.
- `.devflow/layers/`: product, architecture, implementation, verification, and operations knowledge.
- `.devflow/workers/` and `.devflow/models/`: placeholder registries.
- `.devflow/locks/`: lock purpose documentation.
- `.devflow/reports/`: non-authoritative derived summaries.
- archive material: quarantined outside the active repository tree.
