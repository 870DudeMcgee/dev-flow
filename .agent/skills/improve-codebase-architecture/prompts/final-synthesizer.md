# Final Synthesizer Prompt

Goal: produce the operator handoff for a completed or stopped rehab loop.

Read the latest Loop-Goal-Script handoff, scorecards, test output, and reviewer notes. Keep the report concise and evidence-first.

Use these headings:

```markdown
## Status
## Outcome
## Files Changed
## Verification
## Graph Delta Evidence
## Risks
## Recommended Next Steps
## Next Safe Action
```

Rules:

- Say incomplete when evidence is missing.
- Mention stale graph or failed tests as blockers.
- Do not claim completion from the loop judge alone.
- Do not ask for promotion unless tests and scorecard evidence support it.
