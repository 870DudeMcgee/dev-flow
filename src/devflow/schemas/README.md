# Legacy Schemas

These schemas belong to the pre-control-room workflow and are kept only for compatibility and possible future salvage.

They are not the current task-state contract. The current shell-worker control room uses filesystem artifacts under `.devflow/tasks/<task_id>/` and active code in `src/devflow/control_room/`.

Do not treat this directory as active schema authority unless a future control-room document explicitly promotes a schema from here.
