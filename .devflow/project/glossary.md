# Glossary

- **Control room**: Dev-Flow's durable coordination layer around replaceable coding workers.
- **Canonical state**: Machine-readable YAML, JSON, or JSONL files that own current truth.
- **Derived report**: A summary or scorecard generated from canonical evidence. Useful, but not authoritative.
- **Context promotion**: Moving validated information from task-local context up to goal, project, or layer context.
- **Context demotion**: Moving obsolete, rejected, duplicated, or stale material out of active context without deleting history.
- **Worker**: A replaceable execution engine such as a shell command, local model, IDE agent, or future adapter.
