Built Beyond Patch Apply

The current control-plane slices make every worker output inspectable, bounded, replayable, and safe to route through Git.

A1

Artifact Supply Chain

Worker prompts, context packs, reviews, failures, repair proposals, diffs, and reports are stored as hash-checked artifacts with provenance metadata.

C2

Bounded Context Packs

Deterministic repo maps and task contracts build compact role-specific packets, including stale-memory filtering before local workers see context.

R3

Review, Repair, TDD

Review-only workers stay non-mutating, repair loops are bounded, and TDD state transitions record red and green evidence before completion.

D4

DAG And Impact Analysis

Task DAG and impact commands make sequencing, dependency checks, and verification scope explicit instead of leaving them in chat history.

O5

Traces And Evals

Hierarchical traces expose inner workflow spans while deterministic eval fixtures test role prompt behavior without live model calls.

W6

Worktree Parallelism

Task-scoped worktrees let VS Code/Copilot, Codex, and Antigravity work in parallel while devflow keeps ownership and audit metadata centralized.
